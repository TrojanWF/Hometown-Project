## About

This project is a **static hometown-themed webpage for Himachal Pradesh**, created as part of my ongoing frontend learning journey.

It is **not intended to be a full-fledged or production-ready website**. Instead, it serves as a practical showcase of the HTML and CSS concepts I was learning at the time of building it.

The project focuses primarily on **layout, typography, spacing, sizing, and visual presentation** rather than functionality or dynamic content.

As I continue improving my frontend skills, the techniques and design decisions used in this project will continue to evolve.

---

## What I Practiced

This project was built while learning and experimenting with fundamental HTML and CSS concepts, including:

* Structuring webpages with **HTML**
* CSS layouts and positioning
* Typography and text styling
* Spacing and sizing
* Background images
* Flexbox
* Responsive sizing
* Relative CSS units, particularly **`em`**
* Combining multiple CSS properties to create a consistent visual layout

### A Focus on `em`

One of the concepts I was specifically exploring while creating this project was the **`em` CSS unit**.

Using relative units helped me understand how element sizing can depend on typography and how changes to parent or element font sizes can affect the overall layout.
